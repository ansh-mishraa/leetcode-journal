# Landing page overrides

- **Pattern:** Hero-centric + interactive product demo (Recall modes)
- **Hero (first viewport only):** Brand wordmark → one headline → one sentence → CTA pair → full-width Trajectory (no cards, badges, or stats)
- **Atmosphere:** Spectrum orbs + drifting grid + film grain; color remains data (CF rating spectrum)
- **Motion:** Hero rise stagger, Trajectory draw, mastery undertone dash, orb drift, scroll reveals, auto-cycling flow + drill demos (respects `prefers-reduced-motion`)
- **Sections:** Hero → How it works (interactive loop) → Recall modes demo → Differentiator strip → Closing CTA
- **Primary CTA:** Try a problem / Open Recall Engine
- **Secondary:** See the loop (`#how-it-works`)
- **Anti-patterns:** No purple SaaS gradients, no stock photo collage, no card grid in hero
